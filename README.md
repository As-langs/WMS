# WMS 智能助手

**面向 Windows、局域网 Web、iOS 和 Android 的多平台 WMS 辅助工具**

WMS 智能助手围绕企业仓储作业场景，提供物料查询、出库流程辅助、PDA
托盘任务处理、任务记录管理及报表导出能力。项目覆盖电脑端、局域网浏览器和移动端，用户可根据现场设备、网络环境及作业方式选择合适的使用入口。

-   **Windows 电脑端**：支持单台电脑直接使用，也支持在电脑后台运行脚本。
-   **局域网 Web**：电脑端提供局域网 Web
    使用方式，同一局域网内的授权设备可通过浏览器访问。
-   **iOS**：提供 iPhone / iPad IPA 安装包。
-   **Android**：提供 Android  APK 安装包。

> 本项目用于辅助企业 WMS
> 作业。实际可用功能、接口权限及部署方式以仓库当前发布文件、配置和现场
> WMS 环境为准。出库、审核、分配和 PDA
> 确认属于业务写操作，正式使用前请在授权环境中验证。

### 选择使用方式

-   希望电脑在后台运行脚本：选择 Windows
    后台脚本模式，并确保电脑和相关服务按现场要求保持运行。
-   希望同一局域网内多台设备访问：选择局域网 Web
    模式，使用部署电脑提供的局域网访问地址。
-   需要移动端原生应用：根据设备选择 iOS 或 Android。

局域网 Web
的访问地址、端口、账号认证和防火墙要求，以项目中对应版本的部署说明及实际配置为准。不要将内部服务未经安全评估直接暴露到公网。

## 核心业务能力

### 1. WMS 连接与身份验证

-   配置 WMS 服务器地址及登录凭据。
-   配置 PDA 用户标识和仓库标识（具体参数以部署版本为准）。
-   通过 WMS 会话验证确认连接状态。
-   根据平台实现采用相应的本地凭据保护机制。

### 2. 物料查询

-   按物料名称查询 WMS 物料。
-   展示物料名称、编码、规格和单位等信息。
-   返回多个候选物料，供操作人员核对选择。
-   候选排序用于辅助识别，不应代替人工核对。

### 3. 物料出库辅助

-   支持输入物料名称和数量/重量。
-   支持按输入顺序处理多种物料需求。
-   支持常见重量单位换算。
-   在物料规格可识别且单位匹配时，计算包装数量。
-   出库前展示物料和数量信息，要求操作人员核对确认。
-   根据当前平台及 WMS
    接口实现，执行出库单创建、添加明细、审核和分配等流程。

### 4. PDA 托盘任务

-   根据托盘号查询待处理任务。
-   展示物料、规格、计划数量和任务状态。
-   Android 当前实现支持勾选任务、填写实际数量、二次确认及提交出库确认。
-   其他平台的实际数量编辑与提交能力，以对应客户端版本为准。

### 5. 任务记录管理

-   同步和保存 WMS 任务记录。
-   按日期范围筛选任务。
-   按任务类型筛选任务。
-   查看任务基础信息和物料明细。
-   在支持的客户端中搜索任务记录。
-   在支持的版本中导出 XLS 报表。

## 安全与操作注意事项

1.  **使用授权账号**：请使用企业管理员分配的 WMS 账号及仓库参数。
2.  **核对物料**：出库前必须核对物料名称、编码、规格和单位。
3.  **核对数量**：确认实际出库重量、包装数量及托盘实际数量。
4.  **避免重复提交**：网络异常或写操作结果不明确时，先到 WMS
    后台核实单据状态，不要直接重复执行。
5.  **保护内网服务**：局域网 Web 和 Windows
    后台服务应部署在受控网络中；未经安全评估不要暴露到公网。
6.  **备份业务记录**：重要任务记录应按企业要求导出并保存。
7.  **凭据保密**：不要在 README、脚本、截图或公开 Issue
    中提交真实账号、密码、Token、内网敏感信息。
