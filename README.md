# WMS 智能助手

**让仓储出入库操作更加简单、高效、智能**

WMS 对话式出入库助手 · iOS Android 原生客户端 · 自动化任务管理

---

## 📖 项目简介

WMS 智能助手是一款面向仓储管理场景开发的自动化辅助工具，旨在简化传统 WMS 系统的出入库操作流程，提高仓储作业效率。

项目支持通过自然语言输入物料需求，自动识别物料、查询库存信息、匹配物料编码，并完成相应的出入库业务操作。

同时提供托盘出库确认、后台任务监控、历史任务管理、物料明细查询及 Excel 导出等功能。

项目包含原有 Python 自动化程序及 iOS 原生客户端。

## ✨ 核心功能

### 1. 智能生产领料出库

通过对话方式直接输入物料需求，无需手动填写复杂的出库单。

例如：

```text
氯化钠 500kg
```

```text
胆碱 150kg，再领20包硫酸盐
```

主要功能：

- 自动识别物料名称和出库数量。
- 自动查询 WMS 物料信息。
- 多候选物料匹配。
- 支持人工选择正确物料。
- 根据物料规格自动计算出库包数。
- 出库确认卡片。
- 确认后自动提交 WMS 出库业务。
- 显示出库单号及处理结果。

### 2. 托盘实际出库确认

直接输入托盘号即可查询对应出库任务。

例如：

```text
A00666
```

主要功能：

- 自动查询托盘对应的出库任务。
- 获取相关物料信息。
- 展示待确认出库信息。
- 支持修改实际出库数量。
- 提供二次确认机制。
- 提交实际出库确认。
- 返回处理结果。

### 3. 任务监控

自动获取 WMS 后台任务信息，掌握任务执行情况。

主要功能：

- 查询新增任务。
- 查看任务编号、创建时间及托盘号。
- 查看起始库位和任务类型。
- 中文任务状态展示。
- 手动刷新任务状态。
- 点击任务查看完整物料明细。

支持的任务状态包括待执行、执行中、已完成及其他状态。

### 4. 历史任务管理

提供本地历史任务记录及同步管理。

主要功能：

- 首次启动补录最近 90 天历史任务。
- 自动获取上次同步以来新增的任务。
- 本地保存历史任务。
- 自动去重及数据合并。
- 支持日期筛选。
- 支持任务类型筛选。
- 支持按任务编号、托盘号及库位搜索。
- 展开查看完整物料明细。

支持按任务类型筛选：

- 生产领料出库
- 拣货入库
- 其他任务类型

### 5. Excel 导出

支持将历史任务及物料明细导出为 Excel 文件。

任务信息包括：

- 任务编号
- 创建时间
- 任务类型
- 托盘号
- 起始库位
- 任务状态

物料明细包括：

- 物料编码
- 物料名称
- 供应商
- 规格型号
- 批号
- 件数
- 重量
- 入库日期
- 有效日期
- 生产日期
- 质量状态

支持通过 iOS 系统分享功能保存或发送 Excel 文件。

### 6. 新增任务通知

应用运行期间检测新增任务。

主要功能：

- 检测 WMS 新增任务。
- 新任务即时通知。
- 显示新增任务相关信息。
- 打开软件时自动同步后台新增任务。
- 不依赖持续后台轮询。

## 📱 iOS 客户端

iOS 版本采用 SwiftUI 开发，提供原生移动端操作体验。

主要特点：

- 对话式操作界面。
- WMS 服务器连接状态显示。
- 物料智能匹配。
- 出库确认卡片。
- 托盘出库确认。
- 任务监控。
- 历史记录管理。
- Excel 文件导出。
- 新增任务通知。
- 日期及任务类型筛选。

### 运行环境

- macOS
- Xcode
- iOS 设备
- 可访问 WMS 服务器的网络环境

### 编译及安装

1. 下载项目源代码。
2. 使用 Xcode 打开项目。
3. 配置 WMS 服务器地址及相关参数。
4. 选择 iOS 设备或 Generic iOS Device。
5. 编译项目。
6. 通过 Archive 导出 IPA。
7. 使用个人证书完成签名及安装。
