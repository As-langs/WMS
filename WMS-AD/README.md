# WMS Android 客户端

面向 Android 智能手机、工业手持终端 (PDA) 及平板电脑的原生 Android 应用程序。

## 核心特性
- 物料快速查询与智能匹配
- 生产领料出库流程流转
- PDA 托盘待出库任务扫描与实际出库二次确认
- 任务记录与历史状态同步

## 构建方式
使用 Android Studio 打开 `WMS-AD` 目录，或使用命令行执行：
```bash
./gradlew assembleRelease
```
产物 APK 位于 `app/build/outputs/apk/release/`。
正式发布安装包请前往 [Releases 页面](https://github.com/As-langs/WMS/releases) 下载。
