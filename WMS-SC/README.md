# WMS 立体库脚本使用说明书
生产领料出库、PDA 托盘实际出库确认与后台任务监控基于iPhone bark （自动登录配置版）
版本日期：2026-10-28

1. 软件用途
本脚本用于在同一个命令行窗口中处理 WMS 生产领料出库，并监控后台仓储任务。新增的 PDA 托盘实际出库确认功能可通过输入托盘号自动进入，不需要从功能菜单中选择。
脚本会执行真实 WMS 业务操作。创建出库单、添加明细、审核、分配以及 PDA 实际出库确认均可能改变业务数据。请先核对物料、数量、托盘和单据状态。

2. 文件与运行环境
- wms_integrated.py：主程序。
- wms_config.json：本地配置文件，需与主程序放在同一文件夹。
- Windows CMD；需要 Python 3 和 requests 库。
安装依赖：python -m pip install requests
启动：python wms_integrated.py

3. 配置说明
wms_config.json 通常包含 username、password、bark_url、pda_user_id、pda_warehouse_oid。请使用实际环境提供的值；不要公开发送含密码或通知密钥的配置文件。
重要：当前程序的 PDA 配置读取逻辑只接受数字形式的 pda_user_id 与 pda_warehouse_oid。若配置值不是数字，程序会打印警告并回退到脚本内置默认值。必须核对默认值是否适用于当前 WMS 环境，确认无误后再进行真实 PDA 出库确认。

4. 启动后的输入方式
程序登录并验证 WMS 会话后，会进入连续输入模式，不显示功能选择菜单。

4.1 生产领料出库（原有功能）
- 输入“胆碱 150kg”或“盐酸盐 500kg”。
- 支持多项需求，例如“胆碱 150kg，再领20包玉米”。
- 也支持“150公斤胆碱”这种数量在前的格式。
- 若物料只有一个候选项，直接按回车即可选择；多个候选项需输入序号并核对物料信息。
- 程序展示出库单草稿和换算后的计划重量。输入 n 取消，按回车或输入 y 确认。确认后会创建出库单、添加明细、尝试审核、分配，并查询相关任务。

4.2 PDA 托盘实际出库确认（新增功能）
1) 在主输入提示处输入托盘号，例如 A00555 或 A00796。当前自动识别规则为一个英文字母后接五位数字。
2) 程序自动查询该托盘的出库任务，并显示物料名称、编码、规格、任务明细 ID、计划数量和任务状态。
3) 逐项输入机器人实际取出数量。数量必须为大于 0 的整数，且不能超过对应计划数量。
4) 程序展示提交预览，包括托盘号、计划数量、实际数量和剩余数量。确认无误后，必须输入大写 CONFIRM 才会发送真实确认请求；其他输入均取消本次提交。
5) 提交后查看服务器原始响应，并在 WMS 页面核对实际出库和剩余任务。若结果不明确，不要直接重复提交。
在实际数量输入提示处输入 q、quit 或 exit，会放弃当前 PDA 确认流程并返回主输入提示；此时本次 PDA 确认尚未提交。

5. 后台任务监控与通知
- 登录成功后，脚本会启动后台仓储任务监控线程。
- 监控轮询间隔当前为 10 秒。
- 若配置了 bark_url，监控事件可通过 Bark 推送；未配置时监控仍运行，但不会发送 Bark 通知。

6. 退出程序
在主输入提示处输入 q、quit 或 exit 退出程序。也可按 Ctrl+C 中断程序。若中断前已经执行过写操作，请到 WMS 页面核对业务数据；程序中断不会撤销已经提交的操作。

7. 安全与故障处理
- 写操作不会自动重试。网络异常或响应不明确时，先核对 WMS 页面，不要立即重复提交。
- PDA 确认会影响真实库存和任务状态；提交前必须检查托盘号、物料、计划数量和实际数量。
- 如果登录失败，检查 WMS 地址、账号密码、网络连通性和账号权限。
- 如果 PDA 配置提示 ID 不是数字，先核实程序内置默认 ID 是否正确。
- 脚本通过语法检查不等于已完成现场接口验证。
