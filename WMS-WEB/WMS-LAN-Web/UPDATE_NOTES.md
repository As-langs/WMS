# 更新说明：WMS-StockOut-Assistant LAN Web 3.0

基础版本为上游 2.0 Release 与用户提供的 `wms_integrated.py`。上游链接：https://github.com/As-langs/WMS-StockOut-Assistant/releases/tag/2.0

## 新增功能
- 局域网网页：Windows 电脑运行后端，手机、平板通过浏览器访问。
- 对话式聊天界面：直接输入生产领料需求或托盘号。
- 物料候选选择：单一候选项按回车选择第 1 项；多个候选输入数字序号再回车，也可点击候选。
- 生产领料预览：展示物料、规格、单位、计划重量和出口。
- PDA 托盘实际出库：查询托盘任务并填写实际数量。
- 任务监控：查看监控状态和最近任务。
- 免网页口令访问。
- Windows BAT 启动。

## 配置和业务逻辑
网页后端复用原脚本的业务函数。发布包不含真实 `wms_config.json`。原脚本的 PDA 配置只接受纯数字 ID；如果实际系统提供 UUID，需先核实。`Task/List` 查询参数和部分单据状态值也需要按当前 WMS 核对。

## 已知限制和安全
免口令意味着能访问网页的局域网设备可能触发真实出库。仅在可信仓库网络使用，Windows 防火墙仅允许可信网段，禁止公网端口转发。当前使用单 worker，网页草稿状态保存在进程内存，服务重启后未完成草稿可能丢失。写操作超时或结果不明确时先核查 WMS，不要直接重复提交。发布包需在现场完成端到端验收。

## 从 2.0 更新
1. 停止旧服务（按 Ctrl+C）。
2. 备份旧的 `wms_config.json`。
3. 解压新版本到新目录或覆盖程序文件。
4. 保留真实配置，不要用示例文件覆盖。
5. 首次部署创建虚拟环境并安装依赖；已有环境可复用。
6. 双击 `start_wms_web.bat`。本机访问 `http://127.0.0.1:8000`，其他设备访问 `http://电脑IPv4:8000`。
