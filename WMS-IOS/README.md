# WMSStockOutiOS 移动端系统

WMS 原生 iOS 客户端应用，提供智能出库流程、托盘快捷查验、长效任务监控与多线程极速表格导出。

## 快速导航

- 📘 **完整架构设计与交接文档**：请参阅 [HANDOFF.md](./HANDOFF.md)
- 🛠 **一键编译与打包**：运行 `./build_ipa.sh`，生成文件位于 `IPA_Build/WMSStockOutiOS.ipa`
- 💻 **工程打开方式**：使用 Xcode 打开 `WMSStockOutiOS.xcodeproj`

## 核心特性

1. **智能交互与托盘出库**：
   - 支持物料名称、规格、重量直接生成生产领料出库单。
   - **PDA 托盘实际出库确认 (OutTaskConfirm)**：支持在对话主屏或快捷弹窗中输入托盘号（如 `A00412`），查询待出库任务、调整机器人实际取出数量、预览真实出库接口参数与数量核对、二次警示确认后直接向 WMS 发起正式出库提交。
2. **多指标概览仪表盘**：直观统计总任务、执行中、待执行与已完成率，支持点击卡片联动筛选。
3. **受控并发明细预加载**：基于 Swift 结构化并发 `TaskGroup` 维持 8 路并行预加载，消除旧版逐条串行卡顿。
4. **双模式表格导出**：
   - ⚡️ **极速模式**：0.1 秒秒出基础信息，无需网络请求。
   - 📋 **完整明细模式**：并发汇聚物料批次、件数、重量、质检状态等字段。
   - 支持 **Excel 工作表 (.xls)** 与 **通用 CSV (.csv)**（UTF-8 BOM 防乱码）。
5. **本地独立沙盒存储**：自动迁移 `UserDefaults` 至应用沙盒 `Documents/WMSTasks/`，保障数据稳定性与极速加载。
6. **固化应用图标**：内置专属立体立体仓储立体图标，自动化脚本打包直接固化进 IPA 安装包。
